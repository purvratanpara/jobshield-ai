# JobShield AI

ROLE: Act as a senior full-stack developer, UI/UX designer and hackathon mentor.

PROJECT: I am building a website named JobShield AI. It is an AI-powered fake job and internship scam detection platform for students.

PROBLEM: Students receive fake job offers, internship messages, fraudulent recruiter emails and requests for registration fees. They need help identifying warning signs before trusting an offer.

FEATURES:

Home page with attractive hero section.

Job offer checker.

Internship offer checker.

Recruitment message checker.

AI risk score result page.

Suspicious warning signs and explanations.

Safety guide.

Login and signup pages.

User dashboard.

Previous scan history.

TECHNOLOGY: React, JavaScript, HTML, CSS and a clean component-based structure. Prepare the project for Supabase and Gemini API integration.

DESIGN:

Premium, modern cybersecurity website.

Dark navy, blue and purple theme.

Smooth animations.

Beautiful cards and dashboard.

Responsive on mobile and desktop.

Attractive loading and result animations.

Professional hackathon-level design.

TESTING:

Test every navigation link.

Test every form and button.

Check mobile responsiveness.

Check validation and error messages.

Do not leave buttons that look functional but do nothing.

IMPORTANT:
First create the complete frontend and navigation.
Use clearly labeled sample demo results until real AI integration is connected.
Do not claim that demo data is a real AI result.
Keep the code beginner-friendly and explain which files are created.
Act as a professional UI/UX designer. Improve my existing JobShield AI website. Make the website look like a premium AI cybersecurity SaaS product. Improve spacing, typography, gradients, animations, icons, dashboard cards, loading states and mobile responsiveness. Do not remove any existing functionality.
